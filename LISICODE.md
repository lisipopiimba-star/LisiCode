# LISICODE.md — инструкции для LisiCode

Этот файл LisiCode читает автоматически при каждой задаче, если он лежит в корне рабочей папки.
Здесь можно описать проект, стек и правила работы. Ниже — пример для самого проекта LisiCode.

## О проекте

LisiCode — терминальный AI coding agent: работает с файлами проекта, командами, GitHub, Gmail, Google Drive, Telegram и ElevenLabs.
Основной код: `lisicode.py`, интеграции: `lisicode_integrations.py`, тесты: `tests/`.

## Правила работы

1. Не менять функции без прямого указания.
2. Не добавлять новые возможности самостоятельно.
3. Не менять существующий интерфейс без разрешения.
4. Не удалять существующие функции.
5. При точечном исправлении сохранять всё остальное.
6. Перед созданием архива сообщать, что именно будет изменено и что останется нетронутым.
7. Проверять изменения перед выдачей новой сборки.
8. Не утверждать, что тесты пройдены, если они не запускались.
9. Не смешивать основную версию LisiCode и LisiCode Admin.

## Стиль

- Отвечать по-русски, кратко и по делу.
- Код сопровождать только необходимыми комментариями.
