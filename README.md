# LisiCode 1.5.2

LisiCode — локальный AI coding agent для Windows. Версия 1.3.0 добавляет реальные интеграции Gmail, Google Drive и личного Telegram-аккаунта.

## Что нового в 1.5.0 и 1.5.1

- **Провайдеры и автоопределение по ключу:** вставь ключ, и LisiCode сам определит провайдера по префиксу: `gk…` — Target Shop, `sk-ant-` — Anthropic (Claude), `sk-or-` — OpenRouter, `gsk_` — Groq, `xai-` — xAI (Grok), `AIza` — Google Gemini, остальные `sk-` — OpenAI. Если ключ не распознан, провайдера можно выбрать из списка (Enter вместо ключа). Ключи хранятся отдельно для каждого провайдера; смена — командой `/provider`.
- **Модели:** список загружается у самого провайдера (у Target Shop — его собственный). Если провайдер список не отдаёт, название модели вводится вручную; в любом списке тоже можно ввести название вместо номера. У OpenRouter моделей много — работает поиск по части названия.
- **Стриминг ответа:** текст появляется по мере генерации. Если провайдер или модель не поддерживает потоковый режим, LisiCode автоматически делает обычный запрос.
- **Просмотр изменений:** перед перезаписью файла показывается diff (`+`/`-`), для нового файла — первые строки. Подтверждение работает как раньше.
- **LISICODE.md:** если файл лежит в корне рабочей папки, его содержимое добавляется в инструкции агента при каждой задаче (до 20 000 символов). Пример — `LISICODE.md` в этом архиве.
- **Интерфейс в стиле Claude Code:** приветственная рамка, строки инструментов вида `● Read(файл)` с результатом `⎿`, индикатор «Думаю…», линия над полем ввода.

Новых зависимостей нет: `requirements.txt` не менялся.

## Запуск Windows

1. Установите Python 3.10+ и Git for Windows.
2. Распакуйте архив.
3. Запустите `start_windows.bat`. Скрипт установит зависимость Telethon из `requirements.txt`.
4. Настройте API key и рабочую папку.

## Connections

- `/connections` — показать статусы.
- `/connections github` — GitHub PAT.
- `/connections gmail` — Google OAuth для Gmail и Drive.
- `/connections drive` — тот же Google OAuth (оба сервиса используют один аккаунт/токен).
- `/connections telegram` — подключить личный Telegram аккаунт.
- `/connections elevenlabs` — подключить ElevenLabs для генерации озвучки.
- `/connections disconnect google` — отключить Gmail и Drive.
- `/connections disconnect telegram` — удалить Telegram-сессию и локальные параметры API.

### Gmail и Google Drive

1. Откройте Google Cloud Console, создайте проект и включите Gmail API и Google Drive API.
2. Настройте OAuth consent screen. Для личного использования добавьте свой Google-аккаунт в Test users, если приложение находится в режиме Testing.
3. Создайте OAuth Client ID типа **Desktop app** и скачайте JSON.
4. В LisiCode выполните `/connections gmail` и укажите путь к этому JSON. Откроется окно Google OAuth на локальном адресе `127.0.0.1`.
5. Разрешения запрашиваются для поиска/чтения/отправки Gmail и чтения/создания файлов Drive. Google может показывать предупреждение для приложения в режиме тестирования.

Доступные действия агента: поиск и чтение писем; поиск, чтение и создание файлов Drive; отправка письма только после явного подтверждения в терминале. Удаление и перемещение файлов Drive не реализованы.

### Telegram

1. Откройте `https://my.telegram.org`, войдите по номеру телефона и создайте приложение, чтобы получить `api_id` и `api_hash`.
2. Выполните `/connections telegram`, введите API ID, API Hash и номер в международном формате.
3. Введите код подтверждения Telegram; если включена двухэтапная проверка, введите пароль.
4. После подключения агент сможет перечислять диалоги и читать историю выбранного чата.

Агент может отправить сообщение или ответить на конкретное сообщение по ID, но **каждая отправка требует отдельного подтверждения**. Для ответа в стиле собеседника/пользователя попросите агента сначала изучить историю выбранного чата, затем составить ответ. Не отправляйте сообщения людям без проверки текста.

Telethon использует Telegram MTProto API от имени вашего личного аккаунта. Соблюдайте правила Telegram. Файл сессии даёт доступ к аккаунту — никому его не передавайте.

## Данные и безопасность

Настройки хранятся в `~/.lisicode`. Google OAuth token — `google_token.json`, Telegram session — `telegram_session.session`, конфигурация — `config.json`. На системах Unix для токенов выставляются права 0600; на Windows безопасность зависит от ACL учётной записи. Не делитесь папкой `.lisicode`, OAuth JSON или Telegram session.

Отправка Gmail/Telegram и создание файлов Drive запрашивают подтверждение даже при включённом ALLON. Чтение подключённых данных происходит только по запросу агента в рамках текущей задачи. LisiCode не выполняет удаление писем или файлов Drive.

## Остальные команды

`/pet`, `/chat`, `/memory`, `/workspace`, `/model`, `/remote`, `/web`, `/usage`, `ALLON`, `/exit`.

## Ограничения

Интеграции требуют первичной настройки OAuth/Telegram API credentials и доступа к сети. В этой сборке нет Google Calendar, Gmail delete/modify, Drive delete/move, Telegram группового управления/редактирования/удаления сообщений и фонового мониторинга новых сообщений. Реальная авторизация на аккаунтах пользователя должна быть проверена на его устройстве.

## LisiCode Web (1.4.0)

Запусти LisiCode в терминале и введи:

```text
/web
```

LisiCode откроет локальную страницу в браузере. Веб-интерфейс использует ту же сессию, модель, рабочую папку и сохранённые чаты, что и терминал. Сервер слушает только `127.0.0.1`; не пересылай ссылку с токеном другим людям.

## ElevenLabs

Подключение:

```text
/connections elevenlabs
```

Создай API key в настройках аккаунта ElevenLabs и введи его в скрытом запросе LisiCode. После подключения агент может просматривать доступные голоса и генерировать MP3-озвучку. Файлы сохраняются в `audio/` внутри рабочей папки. Генерация расходует лимит/кредиты ElevenLabs, поэтому перед каждым запросом LisiCode спрашивает подтверждение.

Официальная документация API: https://elevenlabs.io/docs/api-reference/text-to-speech/convert
