# LisiCode 1.4.0 — Web UI + ElevenLabs

## Добавлено
- Локальный веб-интерфейс по команде `/web`.
- Минималистичный тёмный чат LisiCode с названием диалога, моделью, историей чатов и полем ввода.
- Сообщения из браузера передаются в тот же основной цикл агента; терминал остаётся доступным.
- История браузера использует те же JSONL-чаты, что и терминал.
- Запросы подтверждения отображаются в браузере и могут быть одобрены там или в терминале.
- Веб-сервер привязан только к `127.0.0.1`, ссылка содержит случайный токен доступа.
- Добавлено подключение ElevenLabs через API key, проверка доступных голосов и генерация MP3 в папку `audio/` рабочего проекта.
- Перед генерацией аудио показывается запрос подтверждения и количество символов.

## Подключение
- `/connections elevenlabs` — ввести API key (скрытый ввод).
- `/connections disconnect elevenlabs` — отключить ElevenLabs.
- `/connections` — показать статус.
- `/web` — запустить браузерный интерфейс.

## Ограничения
- Веб-интерфейс работает на том же компьютере, где запущен LisiCode; доступ из локальной сети не включён.
- Агент обрабатывает одну задачу за раз.
- ElevenLabs в этой версии поддерживает список голосов и Text-to-Speech в MP3. Клонирование голосов, дубляж и сборка видео/SVG пока не реализованы.
- Gmail/Drive и Telegram требуют отдельной настройки учётных данных и реальной авторизации.
