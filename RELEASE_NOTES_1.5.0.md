# LisiCode 1.5.0

Добавлено: провайдеры OpenAI, Groq, OpenRouter, Google Gemini (+ Target Shop), команда `/provider`; стриминг ответа с автоматическим откатом на обычный запрос; просмотр изменений (diff) перед записью файла; поддержка `LISICODE.md`; интерфейс в стиле Claude Code.

Изменено: приветственный экран (вместо ASCII-логотипа — рамка), формат строк инструментов, убрана строка «[SUCCESS] Ответ завершён.», поле ввода «LisiCode >» теперь с линией сверху.

Не тронуто: подтверждения Y/N и ALLON, интеграции (GitHub, Gmail, Drive, Telegram, ElevenLabs), LisiCode Web, Remote, память проекта, чаты, питомец, `start_windows.bat`, `requirements.txt`.

Проверка: автоматические тесты (17) проходят на Linux. Реальные запросы к провайдерам и запуск на Windows не проверялись.
